# Paritya — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Financial inclusion supervisor

- As a supervisor, I want a standard readiness dossier for every AI credit or advice launch, so that pilots cannot scale on slideware alone.
- As a supervisor, I want to revoke a sandbox when exit criteria fail, so that temporary permissions do not become permanent.
- As a supervisor, I want aggregated fairness breach alerts, so that I investigate systemic exclusion early.

### Digital lender model-risk officer

- As a model-risk officer, I want to evidence thin-file coverage and known proxy risks, so that we can defend the model to the supervisor.
- As a model-risk officer, I want conditional approvals with required monitoring metrics, so that we can launch with clear obligations.
- As a model-risk officer, I want to document appeal workflows for declined loans, so that customers are not trapped in a black box.

### Consumer-protection officer

- As a consumer-protection officer, I want plain-language explanation templates tied to each model version, so that call centres can explain declines.
- As a consumer-protection officer, I want complaint themes linked back to specific model versions, so that we fix root causes.

### Conversational banking product owner

- As a product owner, I want language-access test results recorded before claiming nationwide rollout, so that indigenous-language users are not silently excluded.

### Platform administrator

- As a platform administrator, I want role-separated supervisor and provider tenancies, so that firms cannot edit supervisory decisions.
- As a platform administrator, I want playbook templates for credit, fraud, and advice use cases, so that first-time filers are not inventing structure.
